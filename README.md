# Issuer Credit-Risk Early-Warning and Scorecard

## Business problem

Credit analysts need a consistent way to organize issuer information, identify signs of deteriorating credit quality, and explain why an issuer may require closer review. This project will develop an educational early-warning and scorecard workflow that combines financial, market, and qualitative indicators into a transparent monitoring process. It is intended to support analyst judgment—not replace it—and will be built incrementally so that every business rule, transformation, and output can be understood and tested.

## Planned capabilities

- Ingest and validate synthetic or publicly available issuer data.
- Reconcile source data to processed datasets and flag data-quality issues.
- Calculate transparent financial and market-based credit indicators.
- Apply documented scorecard rules and early-warning thresholds.
- Track indicator changes over time and surface issuers for review.
- Explain score drivers, warning signals, and data limitations.
- Present results in a simple Streamlit dashboard.
- Test important business rules and data transformations.

## Planned technology stack

- **Python** for data processing and application logic
- **pandas** for tabular analysis
- **pytest** for automated tests
- **Streamlit** for an interactive dashboard
- **Plotly** or another lightweight charting library for visualization
- **Git and GitHub** for version control and portfolio presentation

The exact dependencies will be selected and documented only when each capability is implemented.

## Data disclaimer

This portfolio project will use **synthetic data or data from documented public sources only**. It must not use, request, or expose confidential, proprietary, personally identifiable, or material non-public information. Synthetic examples will be labeled clearly. Outputs must not be presented as real credit opinions, investment recommendations, or evidence of actual issuer performance.

## Current project status

**Planning.** The repository currently defines the project scope and development standards. No analytical findings, scorecard results, or predictive models have been produced.
